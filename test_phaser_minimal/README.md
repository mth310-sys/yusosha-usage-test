# 遊創舎 Phaser 最小試験機

## 目的

GitHub + GitHub Pages + iPhone中心の開発環境で、Phaserが問題なく動作するかを最小構成で確認する。

## 今回の確認項目

- Phaser本体をCDNから読み込める
- 390 × 600 のゲームキャンバスを表示できる
- iPhoneのタップ入力を取得できる
- Tweenアニメーションが動く
- 既存の遊創舎試験機とは独立して動作する

## 構成

- `index.html` のみで動作
- Phaser 3.90.0
- npm / Node.js / ビルド環境なし
- 画像素材なし
- 音声素材なし

## 操作

黄色い四角をタップする。

`タップ入力 OK` と表示され、四角が回転・拡縮すれば基本試験成功。
