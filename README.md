# YUSOSHA Usage Test

通常Chat + GitHub連携の実運用検証用リポジトリです。

## 構成

- `index.html` — 画面
- `css/style.css` — UIスタイル
- `js/main.js` — カウンター、統計、履歴、CUSTOM STEP

## 実装内容

- +1
- +10
- -1
- RESET
- CUSTOM STEP（1〜25の任意増減）
- 操作回数表示
- 最大値表示
- 直近8件の操作履歴
- 履歴クリア
- スマホ向けレスポンシブ
- 状態表示のアクセシビリティ対応
- 履歴描画をDOM APIで安全に生成

このリポジトリはUsage検証のための隔離環境として使用します。
